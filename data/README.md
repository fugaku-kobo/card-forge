# data — 手塚カードゲーム v7 データ

## ファイル

- `手塚カードゲーム_v7_vX.Y.xlsx` — カード・ルール・スタートデッキを収めた本体。
  **番号が一番大きいものが現行版**。
- 大きな区切りがついたら、次の版番号でファイルを作る(v1.0 → v1.1 …)。
  古い版はそのまま残す = 履歴。
- `backups/` — スクリプト実行時の自動退避先。git 管理外(`.gitignore`)。
  版管理(上記)とは別物の「保険」。

## ツール(`../tools/`)

- `sync_xlsx_v7.py` — ルール/カードの文面を `docs/rule_v7.md` に同期。
- `build_starter_decks.py` — 「スタートデッキ」シート(型番リスト)を生成。

どちらも data/ の**最新版 xlsx を対象**に動き、実行前に `backups/` へ退避する。
版番号を上げる時は、最新版ファイルを `_v1.1.xlsx` 等にコピーしてから編集する。
