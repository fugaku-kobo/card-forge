## 1. 開運コロシアム 総合ルール (Ver.2, 2025/7/31)

### ゲーム概要
- ジャンケンを核とした 2 人対戦 TCG
- デッキ 30 枚ちょうど、同一カードナンバー最大 3 枚

### 勝敗
- **敗北条件 (2 種類)**:
  - バリア 0 枚の状況でバトルに敗北
  - バリア 0 枚の状況でリフレッシュを行う
- バリアが盾的役割(Pokémon の Prize に近いが、減ると消える)

### カード情報
- **ジャンケン**: 《グー》《チョキ》《パー》3 種類、グー>チョキ>パー>グー の循環
- **運値(カチ)**: ジャンケンに勝った時のバトル強度
- **運値(アイコ・マケ)**: ジャンケンに負け or あいこの時のバトル強度
- **コスト**: バトル後のコストフェイズで支払う(デッキトップを使う)
- **属性 / 種族 / カード効果**(独自テキスト)
- **【開運時】【バトル勝利時】【バトル敗北時】** のキーワード効果

### 領域
- **バトルエリア**: 1 枚だけ置ける、戦闘の場
- **コストエリア**: 支払い済みのコスト(横向き表向き、確認後トラッシュへ)
- **デッキ** / **バリア**(5 枚で開始、非公開) / **トラッシュ** / **手札** / **★エリア**

### ターン構造 (5 フェイズ)
1. **ドローフェイズ**: 1 枚ドロー
2. **セットフェイズ**: バトルエリアに 1 枚伏せて置く(または既存をトラッシュして再セット)
3. **オープンフェイズ**: 伏せたカードを表向きに、【開運時】効果発動
4. **バトルフェイズ**: バトル(後述)
5. **コストフェイズ**: バトルエリアのカードのコスト分、デッキトップから支払う

### バトル
1. お互いのバトルエリアのカードのジャンケンを比べる
2. 勝った側: 運値(カチ)を参照、負け or あいこの側: 運値(アイコ・マケ)を参照
3. 運値高い方が勝利、低い方が敗北、同じ場合は引き分け
4. **【バトル勝利時】効果**を勝利側が発動、**【バトル敗北時】効果**を敗北側が発動
5. 敗北したプレイヤーがバリア 0 ならゲーム敗北、1 以上ならバリアトップを手札に加える(=ライフ取得して逆転チャンス)
6. 敗北したカードはトラッシュへ

### 特徴的なメカニクス
- **ジャンケン+運値の二段判定**: 「ジャンケンに勝ったが運値で負ける」という逆転がある
- **バリア取り**: 敗北側がバリアを手札に加える(=ライフが資源にもなる、One Piece と同じ思想)
- **コストフェイズ**: バトル後にデッキを切り崩してコストを払う(リソース管理がバトルと連動)
- **★エリア**: カウンタ的な特殊領域(イベント発動条件などに使う)

### 手塚カードゲームへの示唆
- **バトル時のジャンケン的不確定要素** = 持ち込みバトルに「どんでん返しの可能性」を組み込む参考
- **バリア = ライフカード = 手塚の原稿の代わり**: 没にされたカードを手札に戻す(=逆境からの復活)
- **コストフェイズ = 自動コスト消費**: 「アクションには山を切る代償」を明示化

## 2. デジモンカードゲーム 総合ルール (Ver.3.7, 2026/03/13)

### ゲーム概要
- 「進化」を中核とした 2 人対戦 TCG
- デッキ 50 枚ちょうど + デジタマデッキ 5 枚以下(進化前のカード)
- 同一カードナンバー最大 4 枚

### 勝敗
- **勝利条件**:
  - 相手のセキュリティが 0 枚の状態でアタックを成立させる
  - 相手のデッキが 0 枚でドローできない
- セキュリティ(初期 5 枚)が事実上のライフ

### カード情報
- **カードカテゴリー**: デジタマカード / デジモンカード / テイマーカード / オプションカード
- **進化条件**(コスト含む) / **DP(デジモンパワー)** / **登場コスト** / **使用コスト**
- **色**(7色: 赤/青/黄/緑/黒/紫/白)、多色あり
- **特徴**(形態/属性/タイプを区別)
- **進化元効果**(進化スタック内で有効な効果)
- **リンクカード**(ACE系の追加メカニクス)

### 領域
- **デッキ** / **デジタマデッキ**(進化元の山、別山)
- **エリア**: 「育成エリア」(1 体まで)と「バトルエリア」(枚数無制限)
- **手札** / **トラッシュ** / **セキュリティ**(5 枚)

### メモリーゲージ ⭐ 独自リソース
- 0 を中心に -10〜+10 の数直線
- マーカーで現在のメモリーを示す
- コストを払う = 相手側(右)に動かす
- 相手側 1 以上に到達 = ターン終了(相手にターン渡る)
- **「マイナス状態でターン渡し」というユニーク設計**

### ターン構造 (4 フェイズ)
1. **アクティブフェイズ**: 自分の場のカードを全アクティブ
2. **ドローフェイズ**(先攻 1 ターン目はスキップ): 1 枚ドロー
3. **育成フェイズ**: 「孵化」(デジタマデッキから 1 枚を育成エリアへ) or 「育成エリアからバトルエリアへ移動」 or 「何もしない」
4. **メインフェイズ**: 解決すべき処理がない限り何度でも以下:
   - 登場 / 進化 / 使用(オプションカード) / リンク / アタック / 起動型効果発揮 / パス
   - **パス宣言で即座にメモリー相手側 3 になる**(ターン渡し加速)

### 進化 ⭐⭐⭐ 最大の特徴
- カードカテゴリーに関わらず、**「進化元」**として下に置く
- 進化元の **進化元効果**が継続(下に積まれたカードの効果も生きる)
- 進化時には新カードの効果が誘発(【進化時】キーワード)
- ジョグレス(2 体合体) / バースト進化 / アプ合体 / アセンブリ / デジクロス など複数の進化方式

### バトル
- 攻撃側 DP ≥ 防御側 DP で**防御側が消滅**
- 攻撃側 < 防御側 で**攻撃側が消滅**
- = で**両者消滅**
- セキュリティへの攻撃: セキュリティ 1 枚をめくる(効果発動) → 生き残れば次へ

### 特徴的なメカニクス
- **進化スタック保持**: 進化元が下に積まれ続け、効果も保持
- **メモリーゲージ**: 相手とリソースを共有(マイナス状態でターン渡し)
- **育成エリア**: 場とは別の安全圏で育成
- **セキュリティチェック**: 攻撃のたびに山から効果発動の可能性

### 手塚カードゲームへの示唆
- **進化スタック**: 既に実装済の方式が公式デジモンと完全一致(IPも進化元から合算する仕様は手塚独自で良い)
- **メモリーゲージ**: 「ターン内行動量」を相手と共有するリソース管理を導入可
- **育成エリア = 主人公控え**: 安全圏で進化を準備する場として再解釈
- **セキュリティチェック = 原稿めくり**: 持ち込みバトル成立時に原稿カードを表向きにめくり、効果発動
- **【進化時】キーワード**: 進化時の効果発動を「練り上げボーナス」として明文化

## 3. ONE PIECE CARD GAME 総合ルール (Ver.1.2.0, 2026/1/9)

### ゲーム概要
- リーダーカードと DON!! が中核の 2 人対戦 TCG
- デッキ 50 枚ちょうど(+ リーダー 1 枚 + ドン!!デッキ 10 枚)
- 同一カードナンバー最大 4 枚

### 勝敗
- **敗北条件**:
  - ライフが 0 枚のときに、リーダーがダメージを受ける
  - デッキが 0 枚になる
- ライフは伏せた山(枚数分)、ダメージで 1 枚ずつ手札へ

### カード情報
- **カード種類**: リーダー / キャラクター / イベント / ステージ / ドン!!
- **色**(6色: 赤/緑/青/紫/黒/黄、多色あり、リーダー色縛りでデッキ構築)
- **特徴 / 属性(斬/打/射/特/知)** / **パワー** / **コスト** / **ライフ**(リーダーのみ)
- **【トリガー】**: ライフめくり時に発動可能
- **(アイコン)カウンター**: バトル中の手札効果でパワー上昇

### 領域
- **デッキ** / **ドン!!デッキ** / **手札** / **トラッシュ**
- **場**: リーダーエリア / キャラクターエリア(5 枚まで) / ステージエリア(1 枚まで) / コストエリア(ドン!! 置き場) / ライフ

### ターン構造 (5 フェイズ)
1. **リフレッシュフェイズ**: ターン開始時効果発動、付与されたドン!!をコストエリアへ戻す、全アクティブ
2. **ドローフェイズ**: 1 枚ドロー(先攻 1 ターン目はスキップ)
3. **ドン!!フェイズ**: ドン!!デッキから 2 枚(先攻 1 ターン目は 1 枚)をコストエリアに表向きで置く
4. **メインフェイズ**: 自由順で何度でも以下:
   - キャラクター登場 / イベント発動 / ステージ登場 / ドン!!付与 / バトル / 効果発動
5. **エンドフェイズ**: 「ターン終了時」効果、継続効果リセット

### ドン!! メカニクス ⭐⭐ 独自リソース
- 各ターン +2 枚アクティブ追加(=累積型マナ、最大 10)
- ドン!! 1 枚 = 1 コスト
- **付与**: ドン!! をリーダー or キャラに重ねて、**パワー +1000 / ターン**
- 付与は可能な限り何度でも(集中投資可)
- ターン終了でドン!! は外れてコストエリアに戻る(レスト)

### バトル
- リーダー or キャラがアタッカー、アクティブ → レストで宣言
- **対象**: 相手リーダー or 相手キャラ(レストのみ)
- 攻撃側パワー ≥ 防御側パワー → 防御側 KO(リーダーならダメージ処理)
- 攻撃側 < 防御側 → 何も起きない(攻撃側生存)
- **ブロック・ステップ**: 防御側の【ブロッカー】キャラがいれば、アタック対象をそのキャラに変更
- **カウンター・ステップ**: 防御側が手札から(アイコン)カウンターやイベントカードを使ってパワー上昇

### ダメージ処理
- リーダーへのダメージ 1 = ライフトップを手札へ
- **【トリガー】**: 手札に加える代わりに即座に発動可
- ライフが 0 の状態でリーダーがダメージ → 敗北

### 特徴的なメカニクス
- **DON!! 付与によるパワーブースト**: 累積攻撃力をターンごとに集中投下
- **ライフ=リソース**: 攻撃を受けるとライフが手札に → 不利状況でも逆転リソース
- **トリガー**: ライフからめくれた瞬間の効果発動
- **ブロッカー / カウンター**: 防御側の積極的な反撃機構
- **リーダーカード**: 進化しない 1 枚固定、ゲーム開始時から表向き

### 手塚カードゲームへの示唆
- **DON!! ≒ IP のターン毎自動+2**: ⓪ ドローフェイズで IP を 2 ずつ増やす設計
- **ライフ = 原稿の取り扱い**: 持ち込みダメージで相手の山トップが原稿に行くのではなく、自分のライフが減って手札に来る(防御側に救済)
- **トリガー = 原稿カードに効果**: 原稿ゾーンに送られた瞬間に発動できる効果アイコン
- **ブロッカー = 「かばう」**: 持ち込みアタック時、別キャラが代わりに受ける
- **カウンター = テコ入れ**: 手札のテコ入れカードで防御側がパワー上昇させてバトルを覆す
- **リーダー固定型**: 主人公を進化させない別ルートのオプション

## 4. 遊戯王 マスタールール 2020/4/1 (一部読み取り可)

### ゲーム概要 (一般知識との照合)
- LP 8000 を 0 にすると勝利、または特殊勝利
- メインデッキ 40〜60 枚 + エクストラデッキ 0〜15 枚(融合/シンクロ/エクシーズ/リンク用)
- カード種類: 通常モンスター / 効果モンスター / 魔法 / 罠 / 融合 / シンクロ / エクシーズ / リンク

### ターン構造
1. **ドローフェイズ**(1 枚、先攻 1 ターン目はスキップ任意)
2. **スタンバイフェイズ**
3. **メインフェイズ 1**
4. **バトルフェイズ**
5. **メインフェイズ 2**
6. **エンドフェイズ**(手札 6 枚以下まで捨てる)

### 召喚ルール
- **通常召喚**(1 ターン 1 回): 上級モンスター(Lv5-6)は 1 体リリース、最上級(Lv7+)は 2 体リリース
- **特殊召喚**: 制限なし(各カード固有条件)、融合/シンクロ/エクシーズ/リンクは特殊召喚扱い
- **リンク召喚 (Master Rule 2020)**: エクストラモンスターゾーンとリンクマーカーが先のゾーンに特殊召喚可

### バトル
- 攻撃宣言で相手モンスター or 直接攻撃(モンスターがいない場合のみ)
- 攻撃力対決(攻撃表示同士) / 攻撃力 vs 守備力(守備表示の場合)
- 差分のダメージは攻撃側 or 守備側プレイヤーへ

### 特徴的なメカニクス
- **リリース(アドバンス召喚)**: 上級モンスターを召喚するために場のモンスターを没にする
- **チェーン**: 効果に効果を重ねて発動、後発から解決(LIFO)
- **罠カード**: 1 ターン伏せておかないと使えない(タイムラグ)
- **エクストラデッキ**: 融合/シンクロ/エクシーズ/リンクの素材を場で作って特殊召喚
- **ペンデュラム召喚**: 一度に複数体特殊召喚

### 手塚カードゲームへの示唆
- **リリース召喚 = 強キャラ召喚に没が必要**: Lv3 主人公の進化に没案 2 枚要求などの強化条件
- **チェーン**: 効果に効果を重ねる(現行のテコ入れの正式システム化)
- **罠カードの 1 ターン待機**: テコ入れカードを伏せて 1 ターン経過後に発動可能ルール
- **エクストラデッキ**: 主人公専用の進化山(ライドデッキ風)を別山に
- **手札枚数制限(エンド時 6 枚)**: 手札クリンナップの根拠

| 13: 持ち込みペナルティ | 開運コロシアム コストフェイズ | 公式は **必ずコスト**(山を切る)。手塚も「持ち込み攻撃のたびに山 1 枚没」のルールが現実的 |
| 14: 作品シナジー | Yu-Gi-Oh 部族 / One Piece 色縛り | One Piece は **リーダー色制約でデッキ構築**。手塚も主人公の作品名で「使えるカード制限」が可能 |
| 15: 原稿トリガー | One Piece トリガー / Vanguard トリガー | **手札に加える代わりに発動**(One Piece) と **めくった瞬間効果**(Vanguard) の2方式。手塚は前者が分かりやすい |

### 公式ルールから直接拾える新提案 (3 案)

#### 提案 16: メモリーゲージ式の「IP共有」リソース
**元ネタ**: デジモン メモリーゲージ

メモリーが自分側に偏れば自分の行動 → コスト払って相手側へ → 相手側 1 以上で「相手ターン」へ自動移行。
手塚も「アクティブ点を 1 つの軸で共有」する形で、ターンを越えた連続行動の駆け引きを生む。

#### 提案 17: 「カウンター・ステップ」を持ち込みバトルに追加
**元ネタ**: One Piece カウンター・ステップ

持ち込みバトル中、攻撃側がパワー宣言した後、防御側が手札からテコ入れカードや「(アイコン)カウンター」を発動してパワー上昇できるステップを追加。
1 ターンに 1 度だけでなく、攻撃 1 回ごとに防御側に反撃機会。

#### 提案 18: バトル相打ち(両者没)で原稿 +1
**元ネタ**: デジモン (DP イコールで両者消滅)

持ち込みバトルでパワー対決方式を採用した場合、**両者同パワー → 両者没** ルールを採用。
両者が没になった時、攻撃側だけでなく防御側も原稿 +1 のボーナス(共倒れの美学)。
