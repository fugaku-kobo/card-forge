最終更新: 2026-05-21

> このドキュメントは **2部構成** です。
> - **第1部 🎯 かんたんルール** — 初めての人向け。これだけで1試合遊べる。
> - **第2部 📖 詳細ルール** — 全ルールの正式リファレンス。例外・数値はこちら。
>
> v5.2 の核心:**HPを廃止し「完成度ゲージ」でキャラを原稿化する**。
> バトルは「演出カードの伏せ合い=読み合い」。攻撃は得点ではなく**妨害**。

## 📣 レビューしてくれる人へ

このルールはまだ **テストプレイ前のドラフト** です。特に次の点について意見をください:

分かりにくい所・「ここは他のカードゲームに似すぎ」など、何でも歓迎です。

# 第1部 🎯 かんたんルール

## どんなゲーム?

あなたは **漫画家**。連載キャラを **完成度100%** まで描き上げて原稿にする競争。
**先に原稿を5枚** 完成させたら勝ち。1試合およそ15〜20分。

## 覚えるゾーンは3つだけ

| ゾーン | 役割 |
|---|---|
| **場**(3枠) | 連載中のキャラ。ここで完成度を上げる |
| **原稿** | 完成したキャラの置き場。**5枚で勝利** |
| **手札**(7枚まで) | キャラ・演出カードを持つ |

## 1ターンの流れ

1. **ひらめき+2**、カードを **2枚** 引く
2. **キャラを場に出す / 描き込む**(完成度を上げる)
3. **持ち込みバトル**で相手のキャラを妨害(やりたければ)
4. ターン終了時、**場のキャラ全員の完成度 +20%**

## やることは2つ

| | やり方 | 結果 |
|---|---|---|
| **完成させる** | ターン終了で自動 +20%。ひらめき2を払って「描き込み」+30% | 100%で **原稿+1** |
| **妨害する** | 持ち込みバトルで相手キャラを攻撃 | 勝てば相手の完成度 **−40%** |

## バトル = カードの伏せ合い(読み合いの核心)

1. 攻撃するキャラと、狙う相手キャラを決める
2. お互い手札から **演出カードを0〜2枚伏せる**(攻撃側 → 防御側の順)
3. 同時にめくる → **魅力 + 演出カードの見せ場値** が高い方が勝ち
4. 勝敗で完成度が動く

⚠️ **攻撃して負けると、相手の完成度が +20% 上がる**(逆に手助けになる)。
だから攻撃は「勝てる」と読めた時だけ。ここが駆け引き。

## あと少しで一人前

- **入稿待ち**:完成度100%になったら「入稿待ち」。次の自分のターンまで生き残れば原稿化。その間に攻撃で100%を割られたら失敗。
- **主人公**:各デッキに1人。常に効く能力を持ち、相手の原稿が3枚たまると「覚醒」して強くなる。
- **ひらめき**:カードを出す・描き込む燃料。余ったら「ネタの仕入れ」(ひらめき3→1ドロー)で手札に変えられる。

→ これだけで遊べます。細かい数値・例外は第2部へ。

# 第2部 📖 詳細ルール

## A. 勝敗条件

| 項目 | ルール |
|---|---|
| **勝利** | 自分の原稿ゾーンに原稿が **5枚** たまる |
| **試合上限** | **8ターン**。8ターン終了時は原稿数が多い方の勝ち。同数なら場のキャラの完成度合計が高い方。なお同数なら引き分け |
| **敗北** | 「泣きの一回」を使用済みで、自分の場のキャラが全ていなくなった時 |
| **デッキ切れ** | 敗北にはならない(→K参照) |

## B. ゲームの構成要素

### B-1. カード4種

| 種別 | 説明 | 主なフィールド |
|---|---|---|
| **主人公カード** | デッキに1枚。アイコンゾーンに表向き固定 | passive / active / awakening |
| **キャラカード** | 場に出して完成度を上げる本体 | 魅力 / Lv / イチオシ / 没で得るIP |
| **演出カード** | 手札から伏せて使う万能札 | 見せ場値 / 効果 / 没で得るIP |
| **どんでん返しカード** | 別山(0〜5枚)。覚醒後のみ使用可 | 効果 / 没で得るIP |

- キャラのLv:**Lv1=原案 / Lv2=ネーム / Lv3=清書**。
- **イチオシ**:強力フラグ。原稿化すると原稿+2(通常は+1)。

### B-2. ゾーン

| ゾーン | 役割 |
|---|---|
| アイコンゾーン | 主人公カード1枚を固定 |
| 場 | キャラを置く。**最大3枠** |
| 手札 | **上限7枚** |
| デッキ | メインデッキ(30〜40枚) |
| 伏せゾーン | 罠として伏せた演出カード。**最大2枚** |
| 没案ゾーン | 墓地。ピッチ元・デッキ再生元 |
| 原稿ゾーン | 完成したキャラ=勝利点 |
| どんでん返し別山 | 0〜5枚。覚醒後に参照 |

## C. ゲーム準備

1. 主人公カードをアイコンゾーンに **表向き** で設置。
2. デッキをシャッフルし、**7枚** ドロー。
3. **マリガン**(下記)。
4. 先攻・後攻をランダムに決定。

### マリガン

- 初手に **原案(Lv1)キャラ** が1枚もない場合のみ可能。
- 手札を公開 → シャッフル → 7枚引き直し。
- 回数ペナルティ:
  - 1回目:ペナルティなし
  - 2回目:引き直した7枚のうち1枚をデッキボトムへ
  - 3回目以降:戻す枚数を1枚ずつ増やす

## D. ターン進行(6フェイズ)

| # | フェイズ | 内容 |
|---|---|---|
| ⓞ | **開始** | ひらめき +2。**入稿待ち**のキャラがいれば原稿化(→G)。覚醒条件を満たしていれば以降いつでも覚醒可(→H) |
| ① | **ドロー** | 2枚ドロー(**先攻プレイヤーの1ターン目はスキップ**) |
| ② | **アイディア** | アクションフェイズ(下記) |
| ③ | **持ち込み** | 持ち込みバトルを1回行える(任意。先攻1ターン目はスキップ) |
| ④ | **担当編集** | アクションフェイズ(②と同じ。バトル後の立て直し) |
| ⑤ | **就寝** | 場の各キャラ 完成度 +20%。手札を7枚に調整。ターン終了 |

### アクションフェイズ(②・④で可能な行動)

②と④では、ひらめきが続く限り以下を自由な順で行える:

- **キャラを場に出す**(コスト=カードのひらめき。場は3枠まで)
- **描き込み**(→E)
- **進化**(→E)
- **演出カードを伏せゾーンに伏せる**(最大2)
- **演出カードを表で使用**(効果を即発動)
- **ネタの仕入れ**(ひらめき3 → 1ドロー。回数無制限)
- **主人公のactive起動**(1ターン1回)

→ ③のバトルを②と④で挟むことで、「準備 → 戦闘 → 立て直し」の流れになる。

## E. 完成度システム ★コア

- キャラを場に出した時、**完成度0%**。
- 完成度が上がる経路:

| 経路 | 上昇量 | 備考 |
|---|---|---|
| ⑤就寝フェイズ(自動) | **+20%** | 場の各キャラに |
| 描き込み(②/④) | **+30%** | ひらめき2消費。**1キャラにつき1ターン1回** |
| 進化成功 | **+30%** | 下記 |

- 完成度は **0〜100%**。0%未満には下がらない(0%で止まる)。
- **100%到達 → 「入稿待ち」**(→G)。
- バトルでも完成度が動く(→F)。

### 進化(描き込みとは別物)

- 同名キャラの **Lv1→Lv2→Lv3** の順に、手札から進化先カードを進化元の上に重ねる。
- 条件:進化元が場に出て **1ターン経過** していること。
- 進化したターンも行動できる。進化スタックは保持(下のカードは積まれたまま)。
- 完成度ゲージは引き継ぎ、**進化成功で +30%**。
- 魅力は進化先カードの値に変わる。

## F. 持ち込みバトル(③)★読み合いの核心

### 手順

1. **攻撃宣言**:攻撃側は自陣のキャラ1体(召喚酔いでない)を選び、相手のキャラ1体を対象に指定。**ひらめき1** を支払う。
2. **伏せ**:
   - 攻撃側が手札から演出カードを **0〜2枚** 伏せる(**枚数は相手に見える・中身は隠す**)。
   - 続いて防御側が、その枚数を見てから **0〜2枚** 伏せる。または **降参**(伏せ0枚で攻撃側の勝ち扱い)を選べる。
   - **伏せにIPコストはかからない**(手札を1枚使うのみ)。
3. **一斉オープン**:両者が伏せた演出カードを同時に表にする。
4. **戦闘力計算**:各自 **戦闘力 = キャラの魅力 + 伏せた演出カードの見せ場値の合計**。
5. **結果**:

| 判定 | 効果 |
|---|---|
| 攻撃側の戦闘力が高い(または防御側が降参) | 防御側キャラの完成度 **−40%** |
| 防御側の戦闘力が高い | 攻撃失敗。防御側キャラの完成度 **+20%**(名シーン誕生) |
| 同値(相打ち) | 両者のキャラの完成度 **−20%** |

6. 伏せた演出カードは勝敗に関わらず **全て没案ゾーンへ**(ピッチでIP獲得)。

### バトルのルール

- 持ち込みバトルは **1ターンに1回** まで。
- **先攻プレイヤーの1ターン目はスキップ**。
- **召喚酔い**:場に出したターンのキャラは攻撃側になれない(防御側にはなれる)。進化したターンは攻撃可。
- バトルでキャラが「没」になることはない。完成度が動くだけ(=描き直し)。

> 🎯 **読み合いの肝**:攻撃して負けると相手の完成度が +20% 上がる。攻撃は確信がある時だけの賭け。過剰に演出カードを盛ると、降参されてカードを無駄に失う。

## G. 入稿(原稿化)

- キャラの完成度が **100%到達** → そのキャラは **「入稿待ち」** 状態(マーカー 📤)。
- 入稿待ちのキャラは、描き込み・進化・持ち込みの攻撃ができない(行動済み扱い)。**ただし持ち込みバトルの防御側にはなれる**。
- **次の自分のターンの ⓞ開始フェイズ** に、入稿待ちのキャラが完成度100%以上のままなら **原稿化**:
  - そのキャラを原稿ゾーンへ。**原稿+1**(イチオシキャラなら **+2**)。場の枠が空く。
- 入稿待ちの間(相手のターン)に持ち込みバトル等で完成度が100%未満に下がった場合 → **入稿失敗**。入稿待ちが解除され、通常のキャラに戻る(完成度はその下がった値のまま)。

> 🎯 **読み合いの肝**:入稿待ちは相手に「次のターンに攻めれば阻止できる」と分かる。守る側は防御の演出カードを構え、攻める側は「守りを抜けるか」を読む。

## H. 主人公カード

- デッキに1枚。アイコンゾーンに表向きで固定。場のキャラ数には数えない。**バトルの対象にならない**。
- 3つの能力:

| 能力 | 説明 |
|---|---|
| **passive(常在)** | 場に居る限り常に有効。コスト不要 |
| **active(起動)** | ひらめきコストを払い、1ターン1回起動 |
| **awakening(覚醒)** | 覚醒後、activeの代わりに使える強化版能力 |

### 覚醒

- **条件**:相手の原稿が **3枚以上**。
- **方法**:自分のターン中、好きなタイミングで主人公カードを物理的に裏返す。**1試合1回・戻せない**。
- **覚醒した瞬間**:自陣のキャラ全員の魅力 +5(そのターン中)。
- **覚醒後**:activeがawakening能力に置き換わる。**どんでん返しカード(別山)も使用可能**になる。

## I. ひらめき(IP)と手札

### ひらめき(IP)

- **取得**:
  - ⓞ開始フェイズに自動 **+2**。
  - **ピッチ**:カードが没案ゾーンへ行く瞬間、そのカードの「没で得るIP」分を所有者が獲得。
  - 主人公passive・効果カード依存。
- **用途**:キャラ展開コスト / 描き込み(2)/ ネタの仕入れ(3)/ 持ち込み宣言(1)/ 主人公active / 効果カード。
- 上限なし、累積可。

### 手札

- 初期7枚。①ドローフェイズで毎ターン2枚。
- **上限7枚**。⑤就寝フェイズで超過分を没案ゾーンへ(ピッチ発動)。
- **ネタの仕入れ**:②/④フェイズに、ひらめき3を払って1枚ドロー。1ターンに何度でも可。

> 💡 v5.2では **ひらめきが余りやすく、手札が不足しがち**。ネタの仕入れで余剰IPを手札に変換し、リソースを循環させる(→M参照)。

## J. 演出カード

手札から **伏せて使う** 万能カード。3つの使い方:

1. **バトルの伏せ(③)**:攻撃側・防御側として手札から0〜2枚伏せる。見せ場値で戦闘力を強化。
2. **罠(伏せゾーン)**:②/④で伏せゾーン(最大2)に伏せておく。相手のターンの指定タイミング(主に相手の持ち込みバトル、または入稿)で公開して効果発動。
3. **通常使用(②/④)**:表で使い、カード固有の効果を即発動。

- いずれの使い方でも、使用後は **没案ゾーンへ**(ピッチ)。
- **見せ場値**:バトルで伏せた時の戦闘力ブースト値。強いカードほど見せ場値が高く、没で得るIPは低い(逆相関)。

## K. その他

### 泣きの一回

- 自分の場のキャラが全ていなくなった時、**1試合1回** だけ発動可能。
- 没案ゾーンからLv1(原案)キャラ1体を場に復活(完成度0%)。
- 発動後、次の自分のターンは持ち込みバトル不可。

### デッキ構築

- メインデッキ **30〜40枚**。
- 主人公1枚(デッキ枚数に含めない)。
- どんでん返し 0〜5枚(別山、デッキ枚数に含めない)。
- 同名カードは最大4枚。
- 同じキャラIDは、自分の場に1枚まで(2枚目は出せない)。

### デッキ切れ

- ドロー時にデッキが空なら、没案ゾーンをシャッフルしてデッキにする。
- 没案ゾーンも空ならドローできないだけ(敗北にはならない。8ターン制で決着する)。

## M. v5.1 → v5.2 の変更点

「読み合いに演出カードを使うほど手札が枯渇する」問題への対策:

| 修正 | 内容 | 狙い |
|---|---|---|
| ① ネタの仕入れ追加 | ②/④で ひらめき3 → 1ドロー(回数無制限) | 余剰IPを手札に変換 |
| ② バトル伏せのIPコスト撤廃 | 伏せは手札−1のみ(IP不要) | 浮いたIPをネタの仕入れに回す |
| ③ 手札上限 5→7 | 読み合い用に演出カードをストック可能に | 大勝負前に泣く泣く捨てる事故を防ぐ |

→ **IP余剰 → ネタの仕入れ → 手札 → 演出カード → バトルで没 → ピッチでIP** の循環を確立。
