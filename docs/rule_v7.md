## A. 勝敗

| 項目 | ルール |
|---|---|
| **勝利** | 自分の原稿ゾーンに「**違う名前**」のキャラクターカードが **4枚** 揃う(揃った瞬間に勝利) |
| **ゲーム終了** | ページカード20枚を使い切ったらゲーム終了 → 原稿が多い方の勝ち(同数は引き分け) |
| **想定プレイ時間** | 約20〜25分 |

## B. カードの種類

| 種類 | 説明 |
|---|---|
| **主人公カード** | デッキに1枚。リーダー能力を持つ(進化なし) |
| **キャラクターカード** | 場に出す本体。Lv1(ラフ画)/ Lv2(仕上げ)。**攻撃力**を持つ |
| **急展開カード** | 伏せて使い、相手のターンでも発動できるカード(→O) |
| **ページカード** | 固定30枚から20枚をランダム選出。ゲームの進行=時計(→N) |

## C. ゾーン

- **場**:キャラクターカードを置く。最大3枠
- **伏せゾーン**:急展開カードを伏せる。最大2枚
- **手札 / デッキ**(30枚)
- **没案ゾーン**:墓地
- **原稿ゾーン**:勝利点(キャラがここに4種類)
- **ページトラック**:ページカード20枚を1列に並べる

## D. ゲーム準備

1. 主人公カードを置く。
2. デッキ(30枚)をシャッフルし、初期手札 **5枚** ドロー。
3. **マリガン**:初手が気に入らなければ **1回だけ** 全引き直し(5枚)。
4. ページカード:固定30枚から **20枚をランダム選出**し、裏向きで1列に並べる(ページトラック)。
5. 先攻・後攻をランダムに決定。

### デッキ構築
- メインデッキ30枚(キャラクターカード+急展開カード)+ 主人公1枚。
- 同一IDのカードは **2枚まで**、同名カードは **合計6枚まで**。

## E. ターン進行(5フェイズ)

| # | フェイズ | 内容 |
|---|---|---|
| ① | **ページ送り** | ページカードを1枚めくる。その効果がこのターン全体に適用される |
| ② | **ドロー** | 1枚ドロー(先攻プレイヤーの1ターン目はスキップ) |
| ③ | **メイン** | キャラクターカードを出す(1ターン最大3枚・場は3枠まで)/ 進化 / 急展開カードを伏せる |
| ④ | **バトル** | 攻撃する(下記G) |
| ⑤ | **エンド** | ターン終了 |

## F. キャラクターカード

- **レベル**:Lv1=ラフ画 / Lv2=仕上げ。
- **攻撃力 ★仮**:計算式で決定する(攻撃力は3桁表記)。
  > **攻撃力 = レベル基準(Lv1:200 / Lv2:400)+ 通常変種なら +100 + 主役キャラ(BJ・火の鳥・鉄腕アトム・サファイア)なら +100**
  - 一覧:主役・通常 Lv1:400 / Lv2:600 ・ 主役・能力持ち 300 / 500 ・ その他・通常 300 / 500 ・ その他・能力持ち 200 / 400 ・ ジョークカード 100
  - レンジ Lv1:200〜400 / Lv2:400〜600。重なりがあり「強いLv1=弱いLv2」の競り合いが生まれる。
- **進化**:メインフェイズに、手札の Lv2 を場の同名 Lv1 の上に重ねる(無コスト)。Lv2 を直接場に出すことも可。
- **進化スタックの移動**:進化したキャラ(Lv1+Lv2 が重なった状態)が没案ゾーン・手札・原稿ゾーンへ移動する時、**重なったカードはすべて一緒に移動する**。
- **召喚酔い**:場に出したターンは **攻撃も進化もできない**。
- キーワード **盾持ち / 守り手** を持つことがある(下記H)。

## G. 戦闘(「突破」得点)

### 攻撃
- バトルフェイズに、自分のキャラ1体で相手プレイヤーを攻撃する。**1体につき1ターン1回**(最大3回)。
- 召喚酔いのキャラ・盾持ちのキャラは攻撃できない。

### ブロック
- 攻撃に対し、防御側は場のキャラ1体で割り込める(どのキャラでもブロック可)。
- **1体のキャラがブロックできるのは1ターンに1回**。攻撃側より守備側のキャラが少なければ、差の分の攻撃は素通り(=得点される)。

### 解決
| 状況 | 結果 |
|---|---|
| ブロックされない | **アタッカー → 原稿ゾーン(得点)** |
| アタッカー攻撃力 **>** ブロッカー | ブロッカー → 没案 + **アタッカーは突破して原稿ゾーンへ(得点)** |
| 同値 | 相殺(両方 没案)・得点なし |
| アタッカー **<** ブロッカー | アタッカー → 没案・得点なし(ブロッカーは残る) |

- 得点(原稿入り)したプレイヤーの相手は **1ドロー**。
- 原稿ゾーンに**同じ名前**のキャラが既にいる時に得点した場合 → そのカードは原稿に入らず**没にして2ドロー**。

## H. キーワード

- **盾持ち**:ブロックに使うと、攻撃力に関係なく**攻撃を完全に止める**(突破されない・得点させない)。盾持ち自身も没にならない。この防御は **1回まで**。使い切った後は通常のキャラとして扱う。自分から攻撃はできない(専守の壁)。
- **守り手**:場でのブロックは通常戦闘(突破ルール適用)。加えて、**手札から捨ててブロック**できる → 攻撃を完全に止める(1回・攻撃力比べなし・アタッカーは没にできない)。
- **貫通**:このキャラが攻撃する時、相手の**盾持ち・守り手の「完全に止める」防御を無視**する。盾持ちでブロックされても止まらず、**通常どおり攻撃力比べ**を行い(勝てば突破して原稿ゾーンへ得点)、守り手の「手札から捨ててブロック」も無効化する。戦闘判定を変えるページカード(PG-001〜005)の代替判定下でも、盾無視は有効。※「突破」(攻撃力で勝って原稿入り)とは別概念で、貫通は"止める壁"そのものを無力化するキーワード。

## I. 急展開カード

- デッキに入れるカードタイプ(キャラと混在した30枚デッキ)。一覧は→O。
- メインフェイズに、伏せゾーン(最大2)へ**裏向きでセット**する。
- **セットしたターンは発動できない**。次のターン以降、**自分・相手どちらのターンでも割り込んで**公開・発動できる。
- **発動タイミング**:「**〜した時**」と書かれたカード(KT-001／KT-004)は、その条件を満たした時のみ発動できる。それ以外のカードは任意のタイミングで発動してよい。
- 使用後は没案ゾーンへ。
- 役割:相手ターンに動ける**防御・妨害・読み合い**の手段。

## J. ページカード

- 固定30枚のプール(→N)から20枚をランダム選出し、裏向きでページトラックに並べる。
- 毎ターン①で1枚めくり、その効果が**そのターン全体**に適用される(場の共通ルール)。
- 20枚すべて使い切ったらゲーム終了(→A)。

## K. 主人公(4体)★仮 — それぞれ別の「動詞」で差別化

リーダーごとにプレイ感が大きく変わる(「攻撃力を盛る」だけの被りを解消)。

### ブラック・ジャック「執刀」── コントロール型(操作)
1ターンに1度、キャラ1体を「執刀」する:
- 自分のキャラ → このターン、戦闘で没にならない + 攻撃力 +200(救命)
- 相手のキャラ → このターン、ブロックできない(動きを止める)

→ エースを守り、相手の壁を無力化して縦に押し込む精密なデッキ。

### 鉄腕アトム「7つの能力」── ルーレット型(ガチャ)
1ターンに1度、6面ダイスを振り、出目の能力を発動:

| 出目 | 能力 |
|---|---|
| 1 | 100,000馬力 — 味方1体の攻撃力 +400(このターン) |
| 2 | ジェット噴射 — 味方1体は召喚酔いを無視して攻撃できる |
| 3 | サーチライト — 2ドロー |
| 4 | お尻のマシンガン — 相手1体の攻撃力 −300(このターン) |
| 5 | 人工の心 — 没案ゾーンの自分のキャラ1体を手札に戻す |
| 6 | 無限の可能性 — もう一度振る |

→ 毎ターン何が出るか分からないギャンブル。横展開と噛み合う爆発力。

### ナギ(火の鳥)「輪廻」── 蘇生型
1ターンに1度、**メインフェイズの最初**(手札からキャラを出す前)に、没案ゾーンの自分のキャラ1体を場に出す(召喚酔いあり・空き枠が必要)。**そのキャラは攻撃力 +200(永続)**。

→ 倒されても、より強く甦り押し続ける不死のグラインドデッキ。

### サファイア(リボンの騎士)「ふたつの心」── 変身・適応型(切り替え)
「心」を持ち、**自分のターン開始時に【王子の心】と【お姫さまの心】のどちらかを選ぶ**(初期は王子)。
- 【王子の心】:自分のキャラは攻撃する時、攻撃力 +100。
- 【お姫さまの心】:自分のキャラはブロックする時、攻撃力 +200。

→ 攻守の構えを毎ターン切り替える適応型。リボンの騎士作品の変身シナジーと噛み合う。

> 4者は「操作(BJ)/ ガチャ(アトム)/ 蘇生(ナギ)/ 変身(サファイア)」と動詞が異なり、デッキの回し方そのものが変わる。
