# 手塚カードゲーム 仮ルール v4(アナログ版・テストプレイ用)

> ⚠ **これは確定ルールではありません。テストプレイ用の暫定仕様(draft)です。**
> 確定したルールは `docs/rule_status.md` を参照。本ドキュメントは将来 game_design.md へ反映するか検討するための仮置き場です。

最終更新: 2026-05-13

---

# 1. ゲーム概要

プレイヤーは漫画家。手札のキャラを場に出して **描き進め**、原稿を完成させる競争。
直接戦闘で倒すのではなく、**自分の作品を完成させる速度 vs 相手の進捗を妨害する** の駆け引き。

## 勝利条件
- **原稿 3 枚先取** で勝利
- **6 ターン終了時** の原稿数比較(原稿が多い方の勝ち、同数なら引き分け)

## 敗北条件
- 相手が勝利条件達成
- 自陣全没 + 「泣きの一回」使用済み

# 2. 必要な物品(アナログプレイ前提)

| アイテム | 数 | 用途 |
|---|---|---|
| デッキ(主人公 1 + キャラ + 効果カード) | 各プレイヤー 1 セット | 通常 |
| **進捗トークン**(同色チップ) | 各プレイヤー 12 個 | キャラの上に乗せる(0-3 個) |
| **魅力ブーストマーカー**(+5) | 各プレイヤー 5 個 | バトル時の一時ブースト |
| **ひらめきカウンタ**(d10 ダイス推奨) | 各プレイヤー 1 個 | サイドの IP 残量を物理表示 |
| 原稿ゾーン置き場 | 1 つ | テーブル上のスペース |
| 没ゾーン置き場 | 1 つ | テーブル上のスペース |

---

# 3. セットアップ

1. **先攻決定**: ジャンケンなどでランダムに決定
2. **デッキ準備**: 各プレイヤーがデッキをシャッフル
3. **主人公配置**: 主人公カードを主人公ゾーンに **表向き** で配置(進化なし、ゲーム中ずっと固定)
4. **初期手札**: 7 枚を引く
5. **マリガン**: 初ターンに手札にキャラカードが 1 枚もない場合、公開してシャッフル、7 枚引き直し(回数制限なし、ペナルティなし)

---

# 4. ターン構造(6 フェイズ)

1. **⓪ 開始フェイズ**: ひらめき **+2** 自動加算(カウンタダイスを進める)
2. **① ドローフェイズ**: 2 枚ドロー(先攻 1 ターン目はスキップ)
3. **② アイディアフェイズ**: 手札からキャラを場に出す、効果カード使用
4. **③ 持ち込みフェイズ**: バトル(任意、攻撃したいキャラの数だけ実行可)
5. **④ 担当編集フェイズ**: 主人公スキル発動、集中執筆、完成チェック
6. **⑤ 就寝フェイズ**: 自陣全キャラに進捗トークン **+1**(一括)、手札クリンナップ

# 5. キャラクターカード

## 5.1. ステータス

| 項目 | 範囲 | 意味 |
|---|---|---|
| **魅力** | 5-30(カード固有) | バトル時の強さ(攻撃力・防御力兼用) |
| **コスト** | 1-5 | 場に出すために必要なひらめき |
| **没で得る IP** | 1-5(逆相関) | 没ゾーン送り時に所有者が獲得するひらめき |
| **進捗トークン** | 0-3 個(可変) | カードの上に乗せる、完成度を表す |

## 5.2. 進捗トークン(完成度)

カードの上にトークンを物理的に乗せて完成度を表現:

| トークン数 | 状態 | 効果 |
|:---:|---|---|
| 0 個 | 🔻 下書き | 場に出した直後、**バトルで負けると即没** |
| 1 個 | 📝 ラフ | 通常状態 |
| 2 個 | ✏ ネーム | 完成寸前 |
| 3 個 | ✅ 完成 | **④ フェイズで原稿ゾーンへ送り、原稿 +1**(自信作 +2) |

## 5.3. 進捗の上昇手段

| 手段 | 効果 | 制限 |
|---|---|---|
| **ターン終了時 (⑤)** | 自陣全キャラに +1 一括 | 自動 |
| **集中執筆 (④)** | 任意キャラ 1 体に +1 | ひらめき 1 消費、1 ターン 1 体まで |
| **進化(描き込み)** | 進化したキャラ +1 | 進化処理に内包 |
| **バトル勝利** | 勝者(攻撃側)に +1 | バトル成立時 |
| 効果カード | カード固有 | カード参照 |

## 5.4. 進化(描き込み)

- 同名キャラの **Lv1 → Lv2 → Lv3** で進化
- 進化先カードを進化元の **上に重ねる**(進化スタック保持)
- 進化時にトークン **+1** 自動付与
- **場に出て 1 ターン経過後** でないと進化不可
- 進化したターンに攻撃可

## 5.5. 場の上限

- 自陣 **4 体まで**
- 上限到達時、新キャラを出せない(進化 or 完成で空ける)

# 6. バトル(③ 持ち込みフェイズ)

## 6.1. 攻撃手順

1. **攻撃宣言**: 自陣の任意のキャラ 1 体を選び、**ひらめき 1 消費**
2. **対象指定**: 相手陣のキャラ 1 体を指名(主人公は不可)
3. **ブースト宣言**(任意、両者): 魅力ブーストマーカーをカードの横に置く
   - ひらめき 1 = 魅力 +5
   - ひらめき 2 = 魅力 +10
4. **魅力比較**: 両者の魅力(固定値 + ブースト)を目視で比較
5. **結果適用**:

| 結果 | 効果 |
|---|---|
| 攻撃側勝ち | 防御側のトークン **-1**、攻撃側のトークン **+1** |
| 防御側勝ち | 攻撃側のトークン **-1** |
| 同魅力(相打ち) | 両者のトークン **-1** |

6. **ブーストマーカー回収**: バトル後にマーカーを取り除く

## 6.2. 即没条件

- **トークン 0 個のキャラがバトルで負け、さらに -1 を食らう → 没ゾーン送り**
- 下書き状態の作品がボツになる演出
- 没ゾーン送り時、そのカードの「没で得る IP」分のひらめきを所有者が獲得(ピッチ)

## 6.3. 攻撃の制限

- **召喚酔い**: 場に出したターンのキャラは攻撃不可
- 進化したターンは攻撃可
- 先攻 1 ターン目は ③ フェイズスキップ(攻撃不可)
- 自陣のキャラ全員が各 1 回ずつ攻撃可(ひらめきが許す限り)

## 6.4. 自信作

- 自信作キャラは「魅力 +5」のボーナス(カードに表記)
- 完成時の原稿ボーナス: 通常 +1 → **自信作 +2**
- リスク&リターン: 高魅力で攻めやすいが、相手にも狙われやすい

# 7. 主人公カード

## 7.1. 仕様

- **レベル制廃止**(Lv1/2/3 の段階進化なし)
- 各主人公は 1 枚のカードで完結
- 試合中ずっと主人公ゾーンに居続ける(進化・移動なし)
- バトルの対象にならない(独立、無敵)

## 7.2. 3 つの能力

各主人公カードに以下の 3 種の能力が記載:

| 能力 | 説明 | 例 |
|---|---|---|
| **passive(常在能力)** | 場に居る限り効果発動、コスト不要 | 「自陣に医療キャラがいる間、ターン終了時に手札 +1」 |
| **active(起動能力)** | ひらめきコスト払って 1 ターン 1 回発動 | 「ひらめき 5: 自陣キャラ 1 体のトークン +1」 |
| **awakening(覚醒能力)** | カード裏面に記載、覚醒で起動 | 「ひらめき 3: 自陣全キャラのトークン +1」 |

## 7.3. 覚醒(awakening)

1. **発動条件**: 相手の原稿が **2 枚以上**(暫定)に達した瞬間、覚醒可能状態に
2. **発動方法**: 自分のターン中、好きなタイミングで主人公カードを **物理的に裏返す**
3. 以降、active スキルは裏面の **awakening スキル** に置き換わる
4. 一度裏返したら戻らない(永続)
5. 「ピンチでパワーアップ」のドラゴンボール演出

## 7.4. 主人公カード設計例

### ブラック・ジャック(医療系・サポート型)
- passive: 自陣に医療ジャンルキャラが居る間、ターン終了時に手札 +1
- active(コスト 5): 自陣キャラ 1 体のトークン +1
- awakening(コスト 3): 自陣全キャラのトークン +1

### 鉄腕アトム(SF系・加速型)
- passive: 開始フェイズのひらめき +1(=計 +3/ターン)
- active(コスト 4): 自陣 SF キャラ全員の魅力 +5(ターン中)
- awakening(コスト 6): 場の自陣 SF キャラを 1 体即原稿化(トークン 3 まで上げる)

### 火の鳥(歴史/SF・復活型)
- passive: 自陣キャラが没になる時、50% で没ゾーンから手札へ復活
- active(コスト 8): 没ゾーンから 1 体を場に復活(トークン 1 で復活)
- awakening(コスト 5): 没ゾーンから 2 体を場に復活(トークン 1 で)

# 8. ひらめき(IP)

## 8.1. 取得

| 手段 | 量 |
|---|---|
| ターン開始時(⓪) | 自動 **+2** |
| カード没時(ピッチ) | カード固定値(1-5) |
| インスピレーション送り | 手札を任意で没へ → そのカードの IP |
| 主人公 passive | カード依存 |
| 効果カード | カード依存 |

## 8.2. 使用

| 用途 | コスト |
|---|---|
| キャラ場出し | カードの「コスト」 |
| バトル攻撃宣言 | 1 |
| 魅力ブースト(自分 or 防御側) | 1(+5)or 2(+10)|
| 主人公 active | カード依存(3-9) |
| 集中執筆 | 1 |
| 効果カード | カード依存 |

## 8.3. 上限

- なし(累積可)
- ダイスで数値を物理表示

# 9. 没ゾーン

## 9.1. 没ゾーン送り条件

- バトル敗北で **トークン 0 のキャラ** が負け、さらに -1 を食らった時
- 効果カード(ボツ出し系)で送られた時
- インスピレーション送り(手札を任意で送る)

## 9.2. ピッチシステム

- 没ゾーン送りの瞬間、そのカードの「没で得る IP」分のひらめきを所有者に加算
- 強いカード(コスト高、魅力高)は没で得る IP が低い
- 弱いカード(コスト低、魅力低)は没で得る IP が高い
- → 「弱カードを意図的に没にしてリソース獲得」の戦略が生まれる

## 9.3. デッキ切れ時

- ドロー時にデッキが空 → 没ゾーンをシャッフルしてデッキへ戻す(リフレッシュ)
- 没ゾーンも空なら、ドローできずに敗北

# 10. 効果カード(暫定)

> ⚠ 効果カードの詳細仕様は **16 項目未確定**(`docs/rule_status.md` 参照)。
> 以下は仮設の例。

## 10.1. 種類

| 種類 | 概要 |
|---|---|
| 展開アイディア | 即時効果、使用後は没ゾーンへ |
| テコ入れ | 伏せて配置、相手ターンに発動 |
| どんでん返し | 自分の原稿条件達成で発動可、強力な逆転効果 |

## 10.2. 暫定カード例

| カード | 種類 | コスト | 効果 |
|---|---|---|---|
| ボツ出し | 展開 | 3 | 相手キャラ 1 体のトークン -2 |
| アシスタント雇用 | 展開 | 2 | 自陣キャラ 1 体のトークン +1 |
| ペン入れ集中 | 展開 | 5 | 自陣全キャラのトークン +1 |
| 名シーン | 展開 | 6 | 自陣キャラ 1 体を即完成(トークン 3 へ) |
| 連載打ち切り | テコ入れ | 4 | バトル時、相手キャラのトークンを 0 にする |
| 大ヒット | どんでん返し | 8 | 原稿 +1(自分原稿 2 枚以上時) |

# 11. 泣きの一回

- **発動条件**: 場のキャラが全没した瞬間(1 試合 1 回限り)
- **発動効果**: 没ゾーンから Lv1 キャラ 1 体を場に復活、トークン 1 個で復活
- **ペナルティ**: 次の自分ターンは攻撃不可

# 12. 試合時間の目安

| 段階 | 想定時間 |
|---|---|
| ターン 1-2(序盤) | 約 1 分/ターン |
| ターン 3-4(中盤) | 約 2 分/ターン |
| ターン 5-6(終盤) | 約 3 分/ターン |
| **1 試合合計** | **約 12-18 分** |

# 13. デッキ構築

## 13.1. デッキ枚数

- メインデッキ: **30-50 枚**(暫定、テストプレイで調整)
- 主人公カード 1 枚必須(別山扱いも検討中)

## 13.2. カード制限

- 同名カード最大 4 枚
- 主人公は 1 枚のみ
- 一部のカードに「無制限」フラグあり

## 13.3. デッキバランス(推奨、暫定)

- キャラカード: 60-70%(20-35 枚)
  - Lv1 中心 + 進化先 Lv2/Lv3
- 効果カード: 25-30%(8-15 枚)
  - 展開・テコ入れ・どんでん返しのバランス
- 主人公: 1 枚

# 15. ゲームの楽しさの設計意図

1. **「描き進めて完成させる」が中心**: 漫画家のリアルな仕事を再現
2. **バトル = 妨害**: 「倒して点取り」の陳腐感を脱却
3. **HP 計算ゼロ**: アナログでも遊べる、テンポ抜群
4. **覚醒で逆転ドラマ**: ピンチで主人公がパワーアップ
5. **主人公の個性化**: passive/active/awakening でデッキの方向性が明確
6. **ピッチでネタ廃棄**: 弱カードを意図的に没にする戦略
7. **6 ターン制で短時間**: 1 試合 15 分で回せる、テストプレイ容易
