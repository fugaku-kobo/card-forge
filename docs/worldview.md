# 手塚カードゲーム 世界観 & コアルール再検討(下書き v2)

最終更新: 2026-05-13

このドキュメントはゲームの世界観を「漫画家」中心に統一しつつ、**カードゲームとして真に面白いルール** を設計するための下書き。

特に「HP削って倒す」というRPG的バトルを、漫画家らしくかつ面白い仕組みに置き換えることを目的とする。

---

## 1. 基本コンセプト

> **プレイヤーは漫画家。手札のキャラを育て、名作を生み出す競争をする。**

- ライバル漫画家(対戦相手)に **先に原稿6枚を完成** させた方が勝利
- カード = 自分が描くキャラ・アイディア
- ゲームの根幹は **「人気のあるキャラを描き上げる」競争**

## 2. 世界観マッピング(用語統一案)

### 既に漫画家世界観に乗っている用語(現状維持)

| ゲーム用語 | 世界観上の意味 |
|---|---|
| 原稿 | 完成原稿(勝利点) |
| 没ゾーン | ボツになった案・打ち切られたキャラ |
| 担当編集フェイズ | 編集者と打ち合わせ |
| 持ち込みフェイズ | 編集部への持ち込み |
| 就寝フェイズ | 締切後の仮眠 |
| インスピレーション | 着想・ひらめき |
| 自信作 | 渾身の一作(リスク&リターン高) |
| アイディアフェイズ | ネタ出し |

### まだ世界観に乗っていない用語(変更検討)

| 現状 | 候補(複数案) | コメント |
|---|---|---|
| HP | **人気度** / キャラ人気 / 描き込み度 | 読者人気数値が下がる |
| パワー(攻撃力) | **魅力** / 個性 / インパクト | キャラの強み |
| バトル / 技 | **見せ場** / 名シーン / 魅せる | 戦闘ではなく「魅力比べ」 |
| 倒す / 没にする | **打ち切る** / お蔵入りにする | より漫画家的 |
| IP | **ひらめき** / 構想力 / 画力 | コスト=創作エネルギー |
| デッキ | **ネタ帳** / 構想ノート | 描けるアイディアの山 |
| 手札 | (そのまま「手札」or「描けるアイディア」) | |
| 場 | **連載中の作品** / 執筆中 | 6枠=ページ数の制約 |
| 進化 | **描き込む / 仕上げる** | 別議論 |

### 案 F. 3連載枠争奪型 (Marvel Snap × 漫画家)

**狙い**: 1試合15分の高速対戦。各試合が全く違う展開になる高リプレイ性。

#### コアコンセプト

- 場は **3つの連載枠**(医療誌 / 少年誌 / 青年誌、毎試合ランダム)
- 各枠は独立した戦場、6 ターンで決着
- 6 ターン目終了時、各枠の魅力合計を比較
- 勝った枠の **「掲載点数」** を獲得、合計が高い方が勝ち

#### リソース

- **ひらめき**: 毎ターン +1(最大 6)、ターン毎にフル充填(繰越なし)
- ひらめきでキャラ配置・進化・効果使用

#### 雑誌方針(ロケーション効果) ⭐

試合開始時、3 つの雑誌方針カードを公開:
- 「医療誌」: 自信作キャラ +5 魅力
- 「少年誌」: 主人公キャラ +10 魅力
- 「青年誌」: 各ターン最も魅力の高いキャラ 1 体を裏返す
- 「ホラー誌」: 没ゾーンが大きいプレイヤーの魅力 +1/没枚数
- 「学園誌」: Lv1 キャラ +3 魅力
- 「歴史誌」: 場が空のターン終了時、自動でキャラ 1 体登場

→ 毎試合変わる戦場、デッキ構築・運用が毎回違う

#### 場の構造

```
┌─────────┬─────────┬─────────┐
│ 医療誌  │ 少年誌  │ 青年誌  │
├─────────┼─────────┼─────────┤
│ [相手陣]│ [相手陣]│ [相手陣]│
│ ◇◇◇◇ │ ◇◇◇◇ │ ◇◇◇◇ │
├─────────┼─────────┼─────────┤
│ [自陣]  │ [自陣]  │ [自陣]  │
│ ◇◇◇◇ │ ◇◇◇◇ │ ◇◇◇◇ │
└─────────┴─────────┴─────────┘
   各枠 4 体まで、計 12 体
```

#### ターン進行(6 ターン制、両者同時)

1. **ひらめき +1**(両者同時)
2. **両者の山から 2 枚ドロー**
3. **両者が同時に行動指定**(ひらめきの範囲でキャラ配置・効果使用)
4. **両者の指定を同時公開**
5. **雑誌方針の発動**
6. **連載延長カウント更新**
7. **ターン終了**

#### 進化(描き込み)

- ひらめき消費で同名 Lv+1
- 「描き込み」で **魅力 +5 / 進化効果発動**(Hearthstone Battlecry的)

#### バトル無し / 介入カード

- 直接の戦闘なし(キャラ同士は隣接しても戦わない)
- 効果カードで枠内のキャラを操作:
  - 「ボツ出し」: 相手の枠のキャラ 1 体を退場
  - 「アシスタント雇用」: 自陣のキャラ +3 魅力
  - 「連載延長」: 自陣のキャラのターン継続効果延長
  - 「炎上」: 枠全体の魅力を -5(差し違え)

#### 勝敗

- **6 ターン終了時、各枠で魅力合計比較**
- 勝った枠の数 × 雑誌方針別の「掲載点数」(1〜3)を獲得
- 累計点数が高い方の勝ち
- 同点は引き分け

#### メリット / デメリット

| ✅ メリット | ❌ デメリット |
|---|---|
| 1試合 10-15 分の高速戦 | 既存のカードのHP/技を全捨て(再設計) |
| 毎試合違う雑誌方針 = 高リプレイ性 | 「3レーンに同時配置」UI実装が必要 |
| ブラフ・コミット読み合いの楽しさ | 戦闘ゼロで「攻撃」の爽快感は無い |
| キャラの描き込み = 直感的成長感 | カードバランス全面再設計 |
| 短時間でテストプレイ周回しやすい | 「漫画家らしさ」は中程度(雑誌方針で補強) |

**実装影響**: 中規模(20-30 時間)

### 案 G. 連載スパン成長型 (Digimon × ONE PIECE DON!! × 漫画家)

**狙い**: キャラを連載し続けると強くなる「育てる楽しさ」と「打ち切りリスク」の緊張感。

#### コアコンセプト

- キャラは場に出てからの **ターン経過で強化**(=連載期間ボーナス)
- 連載 1ターン: 魅力 +1
- 連載 3ターン: 「人気作」状態(原稿 +0.5/ターン生産)
- 連載 5ターン: 「看板」状態(原稿 +1/ターン)
- 連載 7ターン: 「マンネリ」状態(自動没のカウントダウン開始)

→ 出したキャラに愛着、でも 7 ターンで自滅。**短期決戦 vs 長期育成**の選択。

#### リソース(ペン入れデッキ) ⭐

ONE PIECE DON!! 方式を採用:

- 別山「ペン入れデッキ」10 枚を試合開始時に用意
- 毎ターン 1 枚アクティブ化(累積)
- ペン入れの使い道:
  - **配置・進化・効果コスト**: 1 ペン入れ = 1 コスト
  - **アタッチ**: 場のキャラに重ねて魅力 +3(=DON!! 付与)
  - ターン終了で外れて戻る

→ 毎ターン使えるリソースが +1 ずつ増える(マナカーブ + 集中投下機構)

#### 戦闘 — 見せ場対決

- 自分のキャラ → 相手のキャラに「見せ場対決」を申し込む(攻撃)
- **魅力比較**(攻撃側 vs 防御側)
- 攻撃側勝ち: 相手キャラ没、自分の原稿 +1(自信作なら +2)
- 防御側勝ち: 攻撃側没、防御側の原稿 +1
- 引き分け: 両者没、互いの原稿 +1
- **アタッチで魅力を一時ブースト可**(ペン入れ追加投下)

→ 攻撃判定がギャンブル要素、安易な攻撃が裏目になる

#### 連載期間カウンタの実装

各キャラインスタンスに `serial_turns` フィールド追加:
- 場に出た時 0、自分のターン終了時に +1
- 進化 = リセット(新装版扱い)
- 7 ターン到達 = マンネリ状態 → 攻撃時 -5 魅力
- 8 ターンで自動没

#### ターン進行(6 フェイズ)

1. **アクティブ**: 自陣の全アクティブ化、ペン入れ +1 枚
2. **ドロー**: 2 枚ドロー
3. **メイン**(自由順): キャラ配置・進化・効果カード・アタッチ・見せ場対決
4. **連載期間処理**: 自陣キャラの `serial_turns` +1、状態判定
5. **原稿生産**: 人気作 = +0.5/枚、看板 = +1/枚
6. **エンド**: アタッチ済ペン入れを返す

#### メリット / デメリット

| ✅ メリット | ❌ デメリット |
|---|---|
| 「育てる楽しさ」が漫画家らしい | 連載期間カウンタの管理がやや煩雑 |
| ペン入れ累積でテンポ感が良い | マンネリ自滅の演出設計が必要 |
| Digimon 進化スタックを活かす | カウンタ表示UIの実装 |
| 既存カードの HP を再利用可能(微改修) | 1試合の長さは可変(8-15ターン) |
| アタッチで集中投下 = 派手な決着 | 「攻撃しない選択」の駆け引きが必要 |

**実装影響**: 中規模(15-25 時間)

### 案 H. 締切クライマックス型 (Hearthstone × Weiss クライマックス × 漫画家)

**狙い**: 10 ターンの連載大河ドラマ。後半ほど派手な手、最終ターン =「最終回」の盛り上がり。

#### コアコンセプト

- 10 ターン制(時間制限あり)
- 毎ターン **ひらめき +1**(最大 10、Hearthstone 方式)
- 試合は 3 段階のドラマ構造で進行
- 8 ターン以降は **クライマックスカード** 解禁

#### 3 段階構造

| 段階 | ターン | 性質 |
|---|---|---|
| **連載初期** | 1-3 | 弱いキャラ展開、軽い小競り合い、原稿 +1 で稼ぐ |
| **連載中盤** | 4-7 | 進化解禁、効果カード活用、本格的なバトル |
| **最終回フェイズ** | 8-10 | クライマックスカード解禁、原稿 ×2 |

#### クライマックスカード(Weiss方式) ⭐

デッキに最大 4 枚投入可、1ターン 1 枚のみ使用:
- **「読者投票 1 位」**: 全ての自陣キャラ魅力 +5(継続)
- **「決め台詞」**: 相手キャラ 1 体を即没
- **「ライバル登場」**: 自陣にライバル(魅力20)を即座に召喚
- **「クライマックス連載」**: 自陣キャラ全員の連載期間 +2
- **「最終決戦」**: 場の全キャラを没にして自分の原稿 ×2

→ 派手・劇的・カタルシス満点

#### バトル — 攻防両ダメージ

- 攻撃宣言時、攻撃側の魅力分を防御側に与え、**防御側も反撃**(防御側の魅力を攻撃側に)
- HP = 人気度、0 で没
- → 安易な攻撃で自分も削れる、戦略的判断

#### 進化(描き込み)

- ひらめき消費で Lv+1
- 進化で **魅力 +3、人気度 +5、進化時効果発動**(Hearthstone Battlecry)

#### 勝敗(複数経路)

- **A. 原稿 8 枚到達**(累計勝利)
- **B. 第 10 ターン終了時、原稿数比較**(最終回サドンデス)
- **C. 主人公への直接攻撃成功**(ライフ削り経路、MTG 風)

→ 3 つの勝ち方 = 3 種類のデッキアーキタイプ

#### メリット / デメリット

| ✅ メリット | ❌ デメリット |
|---|---|
| Hearthstone 系のマナカーブ、安定した成長感 | 大幅なリソースシステム変更 |
| クライマックスカードで派手な逆転劇 | クライマックスのバランス調整が肝心 |
| 10 ターン制で 20-25 分の適切な試合時間 | カード再分類が必要 |
| 複数勝利条件 = デッキ多様性 | 「最終回」演出の実装が必要 |
| 「連載のドラマ感」が漫画家らしい | 直接攻撃ルールの調整必要 |

**実装影響**: 大規模(25-40 時間)

### 案 I. 読者投票ドラマ型 (Vanguard トリガー × 開運コロシアム 運値 × 漫画家)

**狙い**: 毎ターン山めくりのドラマ。一瞬の運で大逆転。「漫画は読者あってこそ」を体現。

#### コアコンセプト

- 通常戦闘(現行に近い)
- 各ターン終了時に **「読者投票」フェイズ** 発生
- 「投票」: 山トップを 2 枚めくる → カードの「読者反応アイコン」で効果発動

#### 読者反応アイコン ⭐

全カードに固有アイコン(5 種類):

| アイコン | 効果 | 想定頻度 |
|---|---|---|
| 🔥 **熱狂** | 自陣のキャラ全員 +2 魅力(1 ターン) | 普通 |
| 💎 **名作** | 自分の原稿 +1(即時) | レア |
| ⚡ **賛否両論** | 相手の場のキャラ全員 -3 人気度 | 普通 |
| 💔 **不評** | 自分の場のキャラ 1 体 -5 人気度 | 一定数 |
| ⭐ **発見** | 山から 1 枚ドロー | 普通 |
| なし | 効果なし | 約 30% |

→ デッキ構築で「自分の山にどのアイコンを増やすか」が戦略

#### 戦闘 — 運値判定 ⭐⭐

開運コロシアム方式を採用:
- 攻撃宣言時、攻撃側 / 防御側ともに山トップを 1 枚めくる
- 各カードの「運値」(0〜5、固有)を参照
- **魅力 + 運値** の合計が高い方の勝ち
- 引き分けは両者没
- めくったカードは没へ(山消費)

→ 魅力高いキャラでも運悪く負ける、ジャイアントキリングの可能性

#### ターン進行

1. **ドロー 2 枚**
2. **メイン**(配置・進化・効果)
3. **バトル**(任意、運値判定)
4. **読者投票フェイズ**: 山トップ 2 枚めくる → アイコン効果発動 → 没へ
5. **エンド**

#### 進化(描き込み)

- ひらめき消費で Lv+1、進化で魅力 +3、運値 +1
- 高 Lv キャラほど安定して勝てる(運要素が薄まる設計)

#### メリット / デメリット

| ✅ メリット | ❌ デメリット |
|---|---|
| 毎ターン「めくり」のドラマ性 | 全カードに新フィールド追加が必要 |
| 「読者投票で原稿+1」=漫画家らしさ最高 | 既存カードに後付け作業 |
| 運要素で初心者でも上級者に勝てる | 「運ゲー」と感じる人もいる |
| デッキ構築で「アイコンの偏り」を作る戦略 | バランス調整が複雑 |
| Vanguard・ワンピのトリガーの楽しさ | カードバランス全面見直し |

**実装影響**: 中規模(15-25 時間)

## 5. 推奨案

### 個別推奨

| 求めるもの | 推奨案 |
|---|---|
| 短時間決着・高リプレイ | **F. 3連載枠争奪型** |
| 育てる楽しさ・深い戦略 | **G. 連載スパン成長型** |
| 派手なドラマ・カタルシス | **H. 締切クライマックス型** |
| 運要素のドラマ・初心者親和性 | **I. 読者投票ドラマ型** |

### 組み合わせ推奨

| 組み合わせ | 効果 |
|---|---|
| **F + I** | 3レーン × トリガーめくり(超ドラマチック) |
| **G + I** | 育成成長 × 運値判定(安定 + 不安定の融合) |
| **H + I** | クライマックス + 読者投票(派手 × 派手) |
| **F + H** | 短時間 × クライマックス(短くドラマチック) |

### 個人的ベスト

**F + G の融合** がベスト。理由:
- F のロケーション効果 = 試合ごとの個性
- G のキャラ成長 = 育てる楽しさ
- 戦闘あり(G の見せ場対決を採用)
- 6 ターン制 → 短時間
- 連載期間ボーナス → 長く守れたキャラに報酬

ただし、複雑になるリスクあり。**まずは F 単体 or G 単体での試作** が現実的。

## 6. 個別アイディア(参考、案に取り込み可)

### 「ペンタブ」「画材」をリソース化?
- IP の代わりに「画材」(インク・トーン・ペン)を消費

## 付録. 旧 5案(A〜E)— 「面白さ不足」で降格

> **これらは初期検討案。世界観は良いがカードゲームとしての面白さが不足、と判定された。
> 参考として残すが、実装する場合は F〜I を優先。**

### 旧案A. 人気バトル型(用語置換+軽微改修)

**問題点**: 仕組みはRPG型のまま、本質的に何も変わらない。

- HP → 人気度、攻撃 → 見せ場、IP → ひらめき(用語のみ変更)
- 仕組みは現状の HP 削り合い
- 実装3-5時間と最小、即試せる
- ✗ カードゲームとして「新しい面白さ」が無い

### 旧案B. 連載枠争い型

**問題点**: 「魅力比較」だけでは駆け引きが浅い。

- HP廃止、場6枠で押し出し
- 編集会議(魅力比較)で勝負
- 反響フェイズで原稿生成
- ✗ 一発勝負の魅力比較は単調

### 旧案C. 名シーン構築型

**問題点**: 戦闘ゼロで「動き」がなく、コンボ理解が高難度。

- バトル完全削除
- キャラ+効果カードで「名シーン」発動
- ボツ出しで妨害
- ✗ パズル的になりすぎ、爽快感不足

### 旧案D. 取材→執筆→反響サイクル型

**問題点**: 取材週=ただドロー、つまらない時間が長い。

- 3週サイクル(取材/執筆/反響)
- 各週で行動制限
- ✗ 漫画家サイクル風だが、ゲームとして退屈

### 旧案E. ハイブリッド(A+C)

**問題点**: A+C なので両者の弱点を継承。

- 通常バトル + 名シーンボーナス
- バトル特化/名シーン特化/ミックスの戦略選択
- ✗ A の浅さ + C の難しさ
