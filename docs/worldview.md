# 手塚カードゲーム 世界観 & コアルール再検討(下書き)

最終更新: 2026-05-13

このドキュメントはゲームの世界観を「漫画家」中心に統一するための下書き。
特に**「HP削って倒す」というRPG的バトルを漫画家らしい仕組みに置き換える**ことを目的とする。

---

## 1. 基本コンセプト

> **プレイヤーは漫画家。手札のキャラを育て、名作を生み出す競争をする。**

- ライバル漫画家(対戦相手)に **先に原稿6枚を完成** させた方が勝利
- カード = 自分が描くキャラ・アイディア
- ゲームの根幹は **「人気のあるキャラを描き上げる」競争**

---

## 2. 世界観マッピング(用語統一案)

### 既に漫画家世界観に乗っている用語(現状維持)

| ゲーム用語 | 世界観上の意味 |
|---|---|
| 原稿 | 完成原稿(勝利点) |
| 没ゾーン | ボツになった案・打ち切られたキャラ |
| 担当編集フェイズ | 編集者と打ち合わせ |
| 持ち込みフェイズ | 編集部への持ち込み |
| 就寝フェイズ | 締切後の仮眠 |
| インスピレーション | 着想・ひらめき |
| 自信作 | 渾身の一作(リスク&リターン高) |
| アイディアフェイズ | ネタ出し |

### まだ世界観に乗っていない用語(変更検討)

| 現状 | 候補(複数案) | コメント |
|---|---|---|
| HP | **人気度** / キャラ人気 / 描き込み度 | 読者人気数値が下がる |
| パワー(攻撃力) | **魅力** / 個性 / インパクト | キャラの強み |
| バトル / 技 | **見せ場** / 名シーン / 魅せる | 戦闘ではなく「魅力比べ」 |
| 倒す / 没にする | **打ち切る** / お蔵入りにする | より漫画家的 |
| IP | **ひらめき** / 構想力 / 画力 | コスト=創作エネルギー |
| デッキ | **ネタ帳** / 構想ノート | 描けるアイディアの山 |
| 手札 | (そのまま「手札」or「描けるアイディア」) | |
| 場 | **連載中の作品** / 執筆中 | 6枠=ページ数の制約 |
| 進化 | **描き込む / 仕上げる** | 既出議論 |

## 3. ✏ コアルール再検討:バトルを「漫画家らしく」する

### 現状の問題

> HP を削って相手キャラを倒す → 原稿が貯まる → 勝利

これは RPG / カードバトル系の標準フォーマット。**漫画家要素ゼロ**。
「なぜキャラ同士がHP削り合うのか?」が物語上説明できない。

---

### 案A. 読者人気バトル(現実装の世界観改修のみ)

**もっとも軽い変更**。コアメカニクスは現状維持、用語のみ世界観に統一。

- HP → **人気度**
- 技を使う → **見せ場を描く**(コスト=ひらめき)
- 相手の人気度を削る = 読者人気を奪う
- 人気度0 = **打ち切り**(=没ゾーン送り)
- 打ち切ったキャラ分、自分の原稿が +1

**世界観的説明**:
「同じ雑誌に連載中のキャラ同士で人気投票競争。読者の支持を奪い合う。
 自分のキャラが目立てば、相手のキャラの読者数は減って打ち切られる。」

| メリット | デメリット |
|---|---|
| 実装変更最小 | 仕組み自体は今と同じ(RPGっぽさ残る) |
| 既存テストプレイ資産活かせる | 「人気を技で奪う」がやや無理筋 |

---

### 案B. 連載枠争い(配置バトル型)

**場=雑誌の連載枠(限り有)** という設定で、押し出し型のバトルに。

- 場の6枠 = 連載雑誌のページ枠
- 相手の連載枠に自分のキャラを「ぶつける」と編集会議が発生
- 編集会議 = **魅力値の比べ合い** or ジャンケン(運要素)
- 負けた方は連載枠を失う(没ゾーン)
- 場を相手キャラから守るほど、自作品が掲載され続けて原稿が貯まる

**世界観的説明**:
「同じ雑誌で連載枠を争う漫画家同士。
 編集者の判断で、より魅力的なキャラが残る。」

| メリット | デメリット |
|---|---|
| HP管理がなくなり、シンプル | 編集会議の判定基準を設計し直す必要 |
| 漫画家らしさ強い | 既存実装の大幅変更 |

---

### 案C. 名シーン構築(コンボ型)

**戦闘排除**。複数のキャラ・効果カードを組み合わせて「名シーン」を作り、原稿に変換。

- 場のキャラ+効果カード+条件 で「名シーンセット」を作る
- セットが完成 → 原稿 +N
- 相手の妨害は「ボツ出し」「やり直し」効果カードで
- キャラはほぼ倒されない、ボツ食らうと手札に戻る or 没

**世界観的説明**:
「ライバル漫画家同士、いかに早く名作を完成させるか。
 直接戦うのではなく、自分の作品クオリティを上げて編集を唸らせる。」

| メリット | デメリット |
|---|---|
| 戦闘ゼロで漫画家らしさ最強 | デッキビルディング&構築知識が必須 |
| パズル/コンボの楽しさ | 学習コスト高い、初心者きつい |
| 手塚カードらしいオリジナリティ | 実装ほぼ全面リライト |

---

### 案D. 取材→執筆→反響 サイクル(ローテーション型)

各ターンで違うフェイズに焦点を当て、漫画家の日常を再現。

- ターン1: **取材**(デッキドロー大量、人気は伸ばせない)
- ターン2: **執筆**(キャラ展開・進化に集中)
- ターン3: **反響**(完成キャラの人気で原稿獲得)
- 相手とは直接戦わず、編集者ポイントで競う

**世界観的説明**:
「漫画家のリアルな1ヶ月サイクルをゲーム化。」

| メリット | デメリット |
|---|---|
| ユニーク | 1試合長すぎる可能性 |
| 教育的 | カードゲームの面白さから遠ざかる |

---

### 案E. ハイブリッド(案A + 案C の中間)

- 通常時は **人気度バトル(案A)** で原稿を貯める
- 場が一定状況になると **名シーン構築(案C)** が発動、原稿大量獲得
- 「人気だけでなく、名作を生み出さなければ勝てない」設計

| メリット | デメリット |
|---|---|
| 戦略の幅が広い | 設計&バランス調整が複雑 |
| 漫画家らしさ + ゲーム性 両立 | 実装ボリューム大 |

---

## 4. おすすめの進め方

### 段階1:案A だけ実装(用語入れ替え)→ 即テスト

世界観だけ統一して現状の仕組みを試す。ここで「やっぱり違う」となったら案B/C/Eへ。

### 段階2:満足できなければ案B or C へ

時間に余裕があるなら **案C(名シーン構築)** が手塚カードゲームらしさ最強。
ただし全面リライト。

### 段階3:バランス調整・確定

最終的にプレイ感が良いものを v3 確定ルールへ。

## 5. 個別アイディア(参考)

### 「ペンタブ」「画材」をリソース化?
- IP の代わりに「画材」(インク・トーン・ペン)を消費
- 種類ごとに使える効果が違う

### 「読者人気投票」ミニフェイズ
- 毎ターン終了時、場のキャラ1体に「人気票」を獲得(+原稿0.5 みたいな)

### 「アシスタント」カード
- 効果カードの一種で、原稿生産を補助
- ターン中限定のサポート役

### 「連載会議」イベント
- 5ターンに1回、場のキャラのうち最も人気が低い1体が自動没
- リアルな打ち切り感

### 「単行本化」ボーナス
- 原稿が3枚貯まったタイミングで「単行本ボーナス」発生
- 中間目標としてゲームに緩急

---

## 6. 検討メモ

- ユーザー的には **直接戦闘=漫画家っぽくない** との指摘
- 案A(用語入れ替え)が最小コストだが、根本解決にならない可能性
- 案C(名シーン構築)は理想形だが、実装重い
- 並行して「進化/練り上げ」のネーミングも要検討(別議論)
